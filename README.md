# Future Hide & Seek 🔍🙈

A fun, safe, futuristic **hide-and-seek game for 2–5 players on one device**,
made for kids aged 9–12. Set in the Neon Future City!

- 🏙️ 22 hiding spots on a glowing city map
- 👥 Pass-and-play: Hiders secretly choose spots, the Seeker searches
- 🎯 3 guesses per Hider (4 on Beginner), smart scoring
- ⚡ 6 power-ups: Scanner Pulse, Robot Clue, Extra Guess, Hologram Decoy, Silent Mode, Secret Tunnel
- 🎚️ 3 difficulties · 8 avatars · tutorial · sound & music · champion screen
- 🔒 No ads, no chat, no accounts, no personal data — everything stays on the device

## Play

- **Locally:** open `public/index.html` in any browser (desktop, tablet or phone)
- **Live:** deployed to Render from the `main` branch (auto-deploys on push)

## Development

```bash
npm install    # dev-only: jsdom for UI tests
npm test       # 21 automated tests (core logic + full DOM playthroughs)
```

See `DESIGN.md` for the full game design and architecture.
